# Bullet database attribution

The bullet data used by the app is retrieved from the [KGW Labs Ballistics bullet database](https://krzysztofgw-pl.github.io/ballistics-bullets/v1/bullets.json), © KGW Labs Ballistics, licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

The local `bullets.json` file records the source and license. The app downloads and caches the published format-1 bundle at runtime when no bundled bullet records are present. Changes or redistributions of the data must comply with CC BY-SA 4.0.
